## 制作说明（可复现）

```
src/
  theme.ts        设计令牌 + 场景帧表
  ui.tsx          背景 / 文字 / 卡片 / 字幕 / 图标等共享组件
  Promo.tsx       时间轴装配（7 段 Sequence + 转场 + 进度条）
  scenes/S0..S6   各段分镜
public/
  shots/          产品真实界面截图（tools/capture-ui.ps1 自动截取）
  bgm.wav         程序合成 BGM（tools/make_audio.py）
tools/
  capture-ui.ps1  UIAutomation 自动切页截图（只扫描，绝不点「开始清理」）
  crop_shots.py   PrintWindow 黑边/标题栏裁切 + 各页特写裁切
  make_audio.py   200 秒 BGM 合成
```

复现：

```bash
# 1. 截图（会把设置写成浅色主题，跑完自动关掉，不删任何东西）
powershell -File tools/capture-ui.ps1
python tools/crop_shots.py
# 2. 打包 + 出片
node node_modules/@remotion/cli/remotion-cli.js bundle src/index.tsx --out-dir build
node node_modules/@remotion/cli/remotion-cli.js render build PureUninstall out/promo.mp4 --codec=h264 --crf=18
```

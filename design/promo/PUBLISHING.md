## 2. B站 简介

### 2.1 现在用这版（商店尚未上架）

```
卸载软件之后，那些没被删掉的东西去哪了？

Windows 自带的卸载程序只负责它自己登记过的那部分——文件目录、注册表键值、开始菜单快捷方式，一样样都可能留下。时间久了就是：磁盘越来越小，系统越来越慢，重装还得带着旧包袱。

【它能做什么】
· 卸载后自动扫描并清理七类残留：文件目录 / 注册表 / 计划任务 / Windows 服务 / 启动项 / 防火墙规则 / WMI 事件订阅
· 每一项残留都列出具体路径和大小，逐条勾选确认，不搞黑箱
· 删除前自动备份（注册表导出 + 文件快照），随时一键还原
· 批量卸载：多选入队，卸载 → 扫描 → 备份 → 清理 一次跑完
· 强制删除：卸载程序坏了、跑不掉的，跳过它直接清残留
· 支持 UWP 商店应用；按需提权，平时不用管理员权限

【实测】
测试机上卸载 Arduino IDE（2.3.10）后扫描：16 项残留、约 882 MB，包含 Program Files 与 AppData 下的目录、注册表 Uninstall 项、以及一堆 MUICache 快捷方式缓存。

【下载】
GitHub（推荐，便携版免安装、自带运行时）：
https://github.com/sqdcz/PureUninstall/releases/latest

微软应用商店：目前还在审核中，通过后我会在这里补上下载方式。

【章节】
00:00  卸载完了，就真的干净了吗
00:10  残留到底藏在哪
00:40  纯净卸载登场
00:55  真机演示：16 项残留 882 MB
01:55  七类扫描范围
02:25  批量卸载 / 强制删除 / 备份还原
02:58  下载与开源信息

【说明】
· 开源 MIT，代码全在 GitHub，欢迎 issue / PR
· 完全本地运行，不收集任何数据；更新检查可以关掉
· 删除操作有安全闸：系统关键路径和服务在黑名单里，不会被误删
· 隐私政策：https://sqdcz.github.io/PureUninstall/privacy.html
· 建议右键「以管理员身份运行」，否则 Program Files、HKLM 这些位置清不掉

#软件 #Windows #系统工具 #开源 #电脑技巧 #卸载

### 置顶评论

```
补几条视频里没细说的：

1. 便携版必须**完整解压**再运行，只拷单个 exe 起不来（依赖同目录的 dll 和资源文件）
2. 建议右键「以管理员身份运行」，不然 Program Files、HKLM、服务这些位置会清理失败
3. 备份在 %LOCALAPPDATA%\PureUninstall\Backups\，删错了可以在「备份还原」页一键还原
4. 崩溃/异常会写 %LOCALAPPDATA%\PureUninstall\crash.log，遇到问题把这个文件发 issue 就行

有想加的功能或者扫不到的残留，评论区说，我记着做。

### 详细描述

```
纯净卸载（PureUninstall）是一款开源的 Windows 深度卸载工具。

Windows 自带的卸载程序只负责清理软件自己登记过的内容。卸载完成后，文件目录、
注册表键值、开始菜单快捷方式、后台服务、计划任务等等往往还留在系统里，时间久了
会让磁盘越来越小、系统越来越慢。

纯净卸载在卸载完成后自动扫描并列出这些残留，逐条确认后统一清理，删除前还会自动
备份，随时可以还原。

■ 七类残留扫描
· 文件与目录：Program Files、AppData、ProgramData 下的残留目录
· 注册表：Uninstall 项、Software 键、App Paths、MUICache、Run 键
· 计划任务：软件注册的定时任务
· Windows 服务：残留的后台服务与驱动
· 启动项：Run 键与启动文件夹
· 防火墙规则：软件添加过的入站/出站规则
· WMI 事件订阅：事件订阅型持久化

■ 主要功能
· 卸载前优先尝试安静卸载（QuietUninstallString），失败回退常规方式
· 等待整个进程树退出后再开始扫描，避免扫到还没退干净的文件
· 扫描结果列出完整路径、类型、大小，逐项勾选
· 删除前自动备份（注册表导出 + 文件快照 + manifest），支持一键还原
· 批量卸载：多选入队，按 卸载 → 扫描 → 备份 → 清理 顺序自动执行
· 强制删除：卸载程序损坏或无法运行时，跳过它直接扫描清理残留
· 支持 UWP / 微软商店应用
· 按需提权：平时以普通权限运行，涉及系统位置时才申请管理员权限
· 深色 / 浅色主题

■ 安全设计
· 系统关键路径与关键服务在内置黑名单中，不会被删除
· 每一项删除前都会复检，备份失败的项不会被删除
· 完全本地运行，不收集任何数据；更新检查可以关闭
· 开源（MIT），代码可自行审计

■ 关于
项目地址：https://github.com/sqdcz/PureUninstall
```

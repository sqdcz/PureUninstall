纯净卸载（PureUninstall）隐私政策

生效日期：2026 年 10 月 21 日 · 最近更新：2026 年 10 月 21 日 · 版本 1.0

摘要：纯净卸载是一款完全本地运行的 Windows 系统工具。我们不收集、不上传、不存储您的任何个人信息。软件唯一可能发生的网络活动是您可随时关闭的「更新检查」，除此之外没有任何数据会离开您的电脑。

1.我们是谁

纯净卸载（PureUninstall，下称"本软件"）是一款用于卸载 Windows 应用程序并清理卸载残留的开源系统工具，由独立开发者（发布者：衰气的船只）开发并维护。本软件通过 GitHub（开源仓库）与微软应用商店分发。

2.我们不收集的信息

本软件不包含任何用户行为追踪、使用情况分析、崩溃遥测上报、广告 SDK 或第三方统计组件。具体而言，我们不会收集或接触：

  • 您的姓名、邮箱、手机号等任何身份信息；
  • 您安装的软件清单、文件内容或任何系统信息（这些数据仅在本机内存中处理，详见第 3 节）；
  • 设备标识符、IP 地址的地理位置、使用时长、点击行为等遥测数据；
  • 本软件崩溃时生成的日志仅写入您本机磁盘，不会发送给任何人。

3.应用权限与本地数据处理说明

为完成卸载与残留清理功能，本软件需要在本地读取以下系统信息，全部处理均在本机完成，不会上传至任何服务器：

读取的数据用途
已安装软件列表（注册表卸载项、UWP 应用包）在软件列表中展示，供您选择卸载目标
残留扫描范围内的文件目录与注册表项在卸载后识别残留文件、注册表、计划任务、服务、启动项等，并在您确认后清理

本软件以标准用户权限启动，不会在启动时要求管理员权限。仅当您主动点击「卸载」「清理」等操作时，才通过 Windows UAC（用户账户控制）申请提权；提权范围仅限于完成该次卸载清理所必需的系统操作。您可以在任何时候拒绝提权，软件将退回标准权限模式。

4.网络活动（唯一的网络请求）

本软件仅在您未手动关闭"更新检查"功能时，访问一个用于获取最新版本号的接口：

项目说明
请求地址默认为 GitHub Releases 公开接口（api.github.com），可在软件「设置」中修改或清空
发送的内容仅一个普通的 HTTPS 版本查询请求；软件本身不附带任何用户标识、设备信息或使用数据
返回的内容最新版本号字符串，仅用于在设置页提示"发现新版本"
如何关闭在「设置」中清空"更新检查地址"并保存，此后本软件不再发起任何网络请求

与所有互联网服务一样，GitHub 作为托管方会按其自身隐私政策记录服务器端访问日志（如 IP 地址）。本软件无法访问、也不会获取这些日志。除此之外，本软件不具备任何网络通信能力。

5.本地数据存储位置

本软件在以下位置保存运行所需数据，全部位于您的电脑本地，您可随时查看或删除：

位置内容
%LOCALAPPDATA%\PureUninstall\Backups\卸载清理前的自动备份（注册表 .reg 导出与文件快照），用于一键还原
%LOCALAPPDATA%\PureUninstall\settings.json您的软件设置（主题、扫描选项等）
%LOCALAPPDATA%\PureUninstall\IconCache\已安装软件的图标缓存
%LOCALAPPDATA%\PureUninstall\crash.log意外错误的本地诊断日志（仅写入本机，不上传）

6.第三方服务

本软件的分发与更新检查涉及以下第三方，其数据处理受各自隐私政策约束：

  • GitHub（微软旗下）：托管开源仓库、软件更新版本信息（GitHub 隐私声明）；
  • 微软应用商店：应用分发渠道（微软隐私声明）。

除上述第 4 节所述更新检查外，本软件不与任何第三方服务通信，不集成任何第三方 SDK。

7.儿童隐私

本软件不面向儿童提供服务，也不会有意收集任何年龄用户的个人信息。由于本软件不收集任何个人数据，因此不存在处理儿童数据的风险。

8.数据安全

本软件遵循"最小必要"原则：仅读取完成卸载清理所必需的系统信息；所有删除操作均需用户逐项确认；删除前默认创建本地备份；系统关键路径与关键服务内置黑名单保护，防止误删导致系统故障。

9.隐私政策的变更

若本软件的功能变化导致数据处理方式调整，我们会更新本页面并同步修订"最近更新"日期。重大变更将通过 GitHub 仓库 Release Notes 说明。建议您定期访问 本页面 查看最新版本。

Privacy Policy — PureUninstall

Summary: PureUninstall is a fully local Windows utility. We do not collect, transmit, or store any of your personal information. The only optional network activity is a user-disableable update check; no other data ever leaves your computer.

No data collection: The app contains no analytics, telemetry, advertising SDKs, or crash reporting. Installed-program lists, registry data, and file scans are processed locally in memory only.

Optional update check: When enabled (default), the app queries a version endpoint (GitHub Releases API by default, configurable or clearable in Settings) to display "new version available". No user identifiers are attached. Clearing the URL in Settings disables all network access.

Local storage: Backups (%LOCALAPPDATA%\PureUninstall\Backups\), settings, icon cache, and crash logs are stored locally only.

Elevation: The app launches as a standard user and requests elevation via UAC only when you explicitly initiate an uninstall or cleanup action.

Third parties: GitHub (hosting/update metadata) and Microsoft Store (distribution). No other third-party SDKs are integrated.
